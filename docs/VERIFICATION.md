## 复现命令与结果

完成 README 中的依赖和 Chromium 安装后，在仓库根目录运行：

```bash
npm run check
npm test
npm run build
npm run build:pages
node --check public/app.js
node --check public/connection.js
node --check public/viewer.js
```

## 界面测试范围

源文件：[tests/ui.test.ts](../tests/ui.test.ts)。

测试通过实际门户表单创建成员、分配权限、编辑环境，并通过两个独立门户 BrowserContext 打开两路远程画布。检查：

- 管理员与成员菜单权限；
- 远程登录、相互独立的输入内容；
- Ctrl+A、中文文本、模拟 composition 事件去重和 Enter 多行输入；
- UI 画质选择、手动重连、异常断线自动重连；
- 重连后仍保留服务端页面中的表单内容；
- 控制权被收回后，迟到的帧解码不能遮住断线提示；
- 390 像素宽度下工作台没有横向溢出；
- 浏览器无未捕获 JavaScript 异常。

中文输入检查包含程序注入的文本与 composition 事件，并不覆盖所有操作系统、输入法和移动端键盘组合。移动布局断言针对门户工作台，不代表完整触屏兼容性验收。

## 连接生命周期回归

源文件：[connection-ui.test.ts](../tests/connection-ui.test.ts)。一个静态前端连接两个独立的真实后端，通过浏览器界面执行操作。

| 场景 | 修复前 | 修复后 |
| --- | --- | --- |
| 登录已失效时退出 | API 返回 401 后界面仍停在工作台 | 明确失效后清除本地登录，立即返回登录页并可重新登录 |
| 检查新后端期间关闭设置 | 请求仍继续，响应到达后可能退出旧登录并切换服务 | 中止检查请求，保留原地址和有效登录 |
| 客户端时钟快 5 分钟 | 客户端把服务端刚签发的票据误判为过期 | 由服务端校验有效期，真实画面连接及断线重连均成功 |

以上三个问题先由回归用例复现，再修改实现使其通过。另验证两条已有要求：正常切换必须先撤销旧后端登录；旧后端退出请求发生网络错误时，不能保存新地址或清除原登录。

## 工作台刷新回归

源文件：[refresh-ui.test.ts](../tests/refresh-ui.test.ts)。使用真实后台和浏览器工作台，通过 Playwright 控制定时器、阻塞指定 HTTP 读取及注入可见性事件：

| 场景 | 断言 |
| --- | --- |
| 单次读取阻塞 21 秒测试时间 | 只有一轮环境读取；刷新按钮处于忙碌状态，不叠加轮询 |
| 首次环境读取返回 503 | 显示连接待检查；下一次轮询恢复真实环境列表与在线状态 |
| 审计读取未完成时切换成员页 | 旧请求被取消，成员页独立加载，不弹出取消导致的网络错误 |
| 审计失败而环境读取成功 | 标记本轮失败，不混合更新部分统计数据 |
| 工作台隐藏 21 秒测试时间 | 不发起轮询；可见事件到达后立即读到后台修改的新名称 |
| 登录被撤销 | 返回可用的登录表单并显示原因，清空旧列表，停止轮询 |

前五个场景在修改前均复现问题，修改后通过。可见性事件测试验证应用的响应逻辑，没有模拟所有操作系统或浏览器的后台节流实现。

## 修复的画面连接状态问题

浏览器图片解码是异步操作。旧客户端只在开始接收时校验连接，导致连接断开后，尚未完成的解码仍可能绘制画面并隐藏断线提示。

回归测试在真实界面中延迟 `createImageBitmap`，撤销控制权后释放解码。修复前断线提示被隐藏，断言失败；修复后，断开连接会更新连接代次并丢弃等待中的旧帧，旧解码不能更改当前界面。此用例随完整测试通过。

## 静态画面样本

2026-10-17 的稳定页面记录中，观察 1,500 ms 得到以下样本；本轮完整测试继续验证去重行为，具体计数保存在新的测试目录中：

```json
{
  "sampleMs": 1500,
  "captured": 11,
  "transmitted": 0,
  "suppressed": 11
}
```

这验证了相同画面不重复发送。系统仍会进行捕获，并约每 2 秒提供一次刷新机会；短采样窗口内零发送不等于长期零带宽，也不意味着捕获 CPU 开销已经消除。动态网页、光标闪烁和视频会产生不同结果。

未进行优化前后同负载的 CPU、内存、带宽或并发容量对照，文档不声明相关提速比例。
