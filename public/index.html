还没有运行服务？

在自己的电脑下载项目，安装 Node.js 24+，然后在项目目录执行：

npm run local -- --with-agent

启动完成后，打开本机工作台即可登录。需要多人远程访问时，再部署 HTTPS 服务并填写上方地址。

环境默认私有。创建后自行登录网站，再选择共享成员。

浏览器在你的设备上运行。创建后下载设备配置，按安装说明启动 Agent。设备离线时不可使用，登录资料保留在设备上。

支持 Cookie、LocalStorage 和受支持的 IndexedDB。只上传 JSON，不上传浏览器目录或脚本；网站的设备绑定等机制可能使登录迁移失败。
